# Everyric Chrome 확장 1.3.1

1.3.0에서 발견된 가사창 조작 버그 두 건을 고친 릴리스입니다. 1.3.0의 변경 내용은 [chrome-v1.3.0](https://github.com/onpe5679/Everyric2/releases/tag/chrome-v1.3.0) 노트를 참고하세요.

## 고친 것

- **줄을 클릭하면 한 줄 위가 잡히던 문제** — 줄 시작 시각으로 정확히 시크하면 브라우저가 그 지점 *이하*의 디코딩 가능한 위치로 붙습니다. 그래서 곡 시간이 줄 시작보다 살짝 앞에 떨어져 한 줄 위가 활성화됐습니다. 줄 안쪽으로 아주 조금 밀어 넣어 의도한 줄에서 시작하게 했습니다.
- **건너뛰었을 때 지나친 줄이 채워지지 않던 문제** — 카라오케 채움이 활성 줄에만 적용되는 구조여서, 앞으로 건너뛰면 지나친 줄들이 빈 채로 남았습니다(되감기 방향은 1.3.0에서 이미 고쳤습니다). 이제 채움 상태가 **현재 재생 위치의 함수**입니다 — 재생으로 지나왔는지 클릭으로 건너뛰었는지와 무관하게 같은 화면이 나옵니다.

## 설치

> Chrome은 웹스토어 외부 확장의 일반 설치를 막기 때문에 개발자 모드로 로드합니다.

1. 아래 **Assets**에서 `Everyric-Chrome-1.3.1.zip`을 받아 압축을 풉니다.
2. `chrome://extensions` 접속 → 우상단 **개발자 모드** 켜기.
3. **압축해제된 확장 프로그램 로드** → 압축 푼 폴더 선택.
   - 이전 버전을 이미 로드해 두셨다면, 같은 폴더 내용을 새 압축 해제본으로 바꾼 뒤 확장 카드의 **새로고침** 버튼만 누르면 됩니다.
4. 서버 기능(싱크 생성·저장된 싱크 조회)을 쓰려면 설정에서 **API 키**를 입력합니다. 서버 주소는 기본값이 채워져 있습니다.
