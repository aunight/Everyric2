# Everyric Chrome 확장 1.5.1

**[한국어](#한국어)** | **[English](#english)** | **[日本語](#日本語)**

## 한국어

- **한도 안내 개선**: 하루 생성 한도(익명 15건)에 도달하면, 이미 싱크가 등록된 곡(원곡·다른 커버)은 검색 화면 하단 **"다른 영상의 싱크 연결"**로 직접 이어 볼 수 있다는 안내를 함께 띄웁니다 — 잇기는 생성 한도와 별개입니다.
- **서버 정책**: 싱크 잇기(연결)는 생성 한도에서 제외되고, 남용 방지를 위한 별도 한도(25건/일)만 적용됩니다.

## English

- **Better limit messaging** — when you hit the daily generation limit (15 for anonymous users), the extension now tells you that a song which already has a sync (original or another cover) can be linked directly via **"Link another video's sync"** at the bottom of the search screen — linking doesn't count against the generation limit.
- **Server policy** — sync linking is excluded from the generation limit and has its own modest anti-abuse cap (25/day).

## 日本語

- **上限案内の改善** — 1日の生成上限(匿名15件)に達した場合、既に同期が登録されている曲(原曲や別のカバー)は検索画面下部の**「別の動画の同期をリンク」**で直接つなげられる案内を表示します — リンクは生成上限の対象外です。
- **サーバーポリシー** — 同期リンクは生成上限から除外され、乱用防止のための別枠上限(1日25件)のみが適用されます。
