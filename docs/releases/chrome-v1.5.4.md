# Everyric Chrome 확장 1.5.4

**[한국어](#한국어)** | **[English](#english)** | **[日本語](#日本語)**

## 한국어

- **권한 축소**: `vocaloidlyrics.miraheze.org` 호스트 권한을 제거했습니다 — MediaWiki API의 익명 CORS(`origin=*`)로 권한 없이 동작함을 확인했습니다. 설치 시 요구하는 사이트 접근이 3곳에서 2곳(기본 서버·vocaro 위키)으로 줄었고, 기능 변화는 없습니다.

## English

- **Fewer permissions** — the `vocaloidlyrics.miraheze.org` host permission has been removed; the MediaWiki API's anonymous CORS (`origin=*`) lets the extension work without it. Site access requested at install drops from 3 hosts to 2 (default server and the vocaro wiki), with no functional change.

## 日本語

- **権限の削減** — `vocaloidlyrics.miraheze.org` のホスト権限を削除しました。MediaWiki APIの匿名CORS(`origin=*`)により権限なしで動作することを確認済みです。インストール時に要求するサイトアクセスが3件から2件(デフォルトサーバー・vocaro Wiki)に減り、機能の変更はありません。
