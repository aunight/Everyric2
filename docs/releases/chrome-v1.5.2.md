# Everyric Chrome 확장 1.5.2

**[한국어](#한국어)** | **[English](#english)** | **[日本語](#日本語)**

## 한국어

- **진행 단계 표시 개선**: 싱크 생성 진행 칩의 단계명을 표시 언어에 맞춰 보여줍니다(지금까지는 언어 설정과 무관하게 한국어로 표시). "다운로드" 표기를 **"오디오 준비"**로, "전사 정렬"을 **"가사 정렬"**로 바꿔 실제 동작(오디오 취득·정렬은 서버가 수행)을 정확히 반영합니다.
- **문서**: 공개 서비스 운영 시 원작자 고지 요청(비구속)을 NOTICE·README에 명시.

## English

- **Progress stage labels** — the generation progress chip now shows stage names in your display language (previously always Korean). "Download" is now **"Preparing audio"** and alignment is labeled **"Aligning lyrics"**, accurately reflecting that audio acquisition and alignment happen on the server.
- **Docs** — a non-binding request to notify the original author when operating a public service is now stated in NOTICE/README.

## 日本語

- **進行段階表示の改善** — 同期生成の進行チップの段階名を表示言語に合わせて表示します(これまでは言語設定に関係なく韓国語でした)。「ダウンロード」は**「音源準備」**に、整列は**「歌詞アライメント」**に変更し、音源の取得・整列がサーバー側で行われる実際の動作を正確に反映しました。
- **ドキュメント** — 公開サービス運営時に原作者へ通知をお願いする(拘束力のない)要請をNOTICE・READMEに明記しました。
