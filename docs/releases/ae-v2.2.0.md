# Everyric Studio for After Effects v2.2.0

크롬 확장 1.5.0이 연 **다국어 번역·발음**을 AE 패널도 따라갑니다. 한국어·영어·일본어 번역을 골라 받고, 발음은 한글·로마자·가나 중에서 원문에 맞는 표기로 봅니다.

## 새 기능

### 번역 언어 선택

싱크 탭에서 **번역 언어**를 한국어·English·日本語 중에 고릅니다. 서버는 이 곡에 어떤 언어가 준비돼 있는지 함께 알려주고, **이미 받아 둔 언어 사이는 재조회 없이 즉시 전환**됩니다. 고른 언어의 번역이 아직 없으면 준비된 언어를 알려줍니다.

### 발음 표기 선택

**발음 표기**를 자동·한글·romaji·かな 중에 고릅니다. 자동은 번역 언어를 따릅니다 — 영어면 로마자, 일본어면 가나, 그 밖은 한글. 커팅 화면의 발음 참고 줄도 고른 표기로 나옵니다.

크롬 확장과 **같은 규칙**을 씁니다. 두 클라이언트가 같은 곡에서 서로 다른 표기를 보이지 않습니다.

## 알아두실 것

**예전에 만들어진 싱크에는 로마자·가나 표기가 없습니다.** 그 경우 발음 줄을 **비웁니다** — 한글 독음을 대신 보여주지 않습니다. 로마자를 보려고 고른 사람에게 한글이 나오면 그게 더 나쁘기 때문입니다. 한글 표기를 고르면 예전 싱크에서도 그대로 보입니다.

곡을 새로 생성하거나 최근에 만들어진 싱크를 받으면 세 표기가 모두 들어옵니다.

## 설치

1. 릴리스 에셋에서 `Everyric-Studio-2.2.0.zxp` 다운로드
2. [aescripts ZXP Installer](https://aescripts.com/learn/zxp-installer/)로 열기
3. After Effects 재시작 → **Window → Extensions → Everyric Studio**

ZXP Installer를 쓸 수 없는 경우 `Everyric-Studio-2.2.0-manual.zip`을 받아 `install.bat`을 실행하세요.

## 요구 사항

| 용도 | 요구 사항 |
|---|---|
| 패널 (JSON 불러오기 · 타이포 생성 · 글자 커팅) | After Effects 2024(24.0) 이상 · Windows |
| 서버 싱크 가져오기 (선택) | 인터넷 연결 |
| 로컬 싱크 생성 (선택) | 패널 내 "엔진 설치" 버튼으로 자동 설치 (CPU 약 300MB / CUDA 약 2.5GB) |

## 알려진 제한

- Windows 전용입니다. macOS는 지원하지 않습니다.
- 자가 서명 인증서로 서명되어 있어 일부 환경에서 설치 시 경고가 표시될 수 있습니다.
- 로컬 JSON으로 불러온 싱크는 언어를 바꿀 수 없습니다(서버에서 받은 싱크만 전환됩니다).
