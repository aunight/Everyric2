# Everyric Studio for After Effects v2.1.0

가사를 **글자 사이에서 잘라** 레이어를 나누는 커팅 모드가 들어갔습니다. 자동 분할이 못 맞추는 호흡을 손으로 확정하는 작업이고, 자르는 순간 타이밍까지 함께 맞춰집니다. 더불어 서버에 이미 만들어진 싱크를 영상 ID로 끌어오고, Python 런타임을 ZXP에 동봉해 설치를 줄였습니다.

## 새 기능

### 글자 커팅 (04번 탭)

타임라인에 올라간 텍스트 레이어를 골라 **글자 사이를 누르면 그 자리에서 잘립니다.** 잘린 자리를 다시 누르면 붙고, 경계를 좌우로 끌면 시각을 미세 조정합니다(Shift로 더 곱게).

정렬 결과가 이미 글자 단위 타이밍을 들고 있어서, 자를 자리를 고르는 순간 시각이 확정됩니다 — **분리와 타이밍 정렬이 한 동작**입니다.

- 각 조각은 **원래 그 글자가 있던 자리**에 놓입니다. 한 줄이 왼쪽부터 차례로 채워집니다.
  («원래 위치 유지»를 켜면 전부 원본 자리에 겹쳐 둡니다.)
- 조각은 제 시각에 나타나 **줄이 끝날 때까지 남습니다**. 앞 글자가 사라지지 않습니다.
  («차례로 교체»를 고르면 다음 조각이 앞 조각을 대신합니다.)
- 조각은 원본의 **복제**라 폰트·색·자간·이펙트·마스크·부모 관계가 그대로 따라갑니다.
- AE에서 레이어를 고르기만 하면 패널이 따라옵니다. 버튼을 누를 필요가 없습니다.
- 글자마다 시각이, 줄 아래에 발음이 표시됩니다. 일본어 가사에서 어디를 끊을지 판단할 때 씁니다.
- 잠긴 레이어, Source Text 키프레임이 있는 레이어, 여러 줄 텍스트는 이유를 밝히고 거부합니다.

### 서버 싱크 가져오기

유튜브 주소나 영상 ID를 붙여넣으면 서버에 이미 만들어진 싱크를 번역·발음과 함께 받아옵니다. 조회 전용이며, 패널이 서버에 생성을 요청하지는 않습니다.

### 컴포지션별 싱크 저장

불러온 싱크가 **컴포지션마다 저장**됩니다. 패널을 닫았다 열어도 그대로 돌아오고, 컴포지션을 옮기면 그쪽 싱크로 갈아탑니다. 파일을 다시 고르거나 정렬을 다시 돌릴 일이 없습니다.

### Python 런타임 동봉

ZXP에 Python 3.11이 들어 있습니다. 설치할 때 `%LOCALAPPDATA%\Everyric`로 복사해 쓰므로 **패널을 업데이트해도 이미 깔린 엔진이 그대로 남습니다.** 모델 캐시는 사용자 홈의 기본 HuggingFace 위치를 그대로 쓰기 때문에, 패널이나 엔진을 갱신해도 수 GB를 다시 받지 않습니다.

## 고친 것

- **후렴이 반복되는 곡에서 2절 레이어가 1절의 시각을 가져가던 문제.** 텍스트가 같은 줄이 여럿이면 이제 시간이 겹치는 쪽을 잡습니다.
- **조각의 out 지점이 밀려나던 문제.** AE에서 `inPoint`는 트림이 아니라 이동이라, 순서를 바로잡았습니다.
- **생성 레이어에 인위적인 이름을 붙이던 것.** AE 기본대로 텍스트 내용이 곧 레이어 이름이 됩니다. 생성물 식별은 레이어 코멘트가 맡습니다.

## 알아두실 것

- **가사 언어를 지원하는 폰트를 쓰세요.** 폰트에 글자의 글리프가 없으면 폭을 잴 수 없어 조각을 제자리에 놓지 못합니다. 그 경우 조각을 옮기지 않고 경고를 띄웁니다. (예: 한글 전용 폰트로 일본어 가사를 다루는 경우)
- 자른 조각 사이에 남는 간격은 오차가 아니라 원본에도 있던 자간·공백입니다.

## 설치

1. 릴리스 에셋에서 `Everyric-Studio-2.1.0.zxp` 다운로드
2. [aescripts ZXP Installer](https://aescripts.com/learn/zxp-installer/)로 열기
3. After Effects 재시작 → **Window → Extensions → Everyric Studio**

ZXP Installer를 쓸 수 없는 경우 `Everyric-Studio-2.1.0-manual.zip`을 받아 `install.bat`을 실행하세요.

## 요구 사항

| 용도 | 요구 사항 |
|---|---|
| 패널 (JSON 불러오기 · 타이포 생성 · 글자 커팅) | After Effects 2024(24.0) 이상 · Windows |
| 로컬 싱크 생성 (선택) | 패널 내 "엔진 설치" 버튼으로 자동 설치 (CPU 약 300MB / CUDA 약 2.5GB) |

## 알려진 제한

- Windows 전용입니다. macOS는 지원하지 않습니다.
- 자가 서명 인증서로 서명되어 있어 일부 환경에서 설치 시 경고가 표시될 수 있습니다.
- 프로젝트를 저장하지 않은 상태에서는 컴포지션별 싱크 저장이 그 세션 동안만 유지됩니다.
