# 同語言翻譯隱藏設計

## Problem 1-Pager

### 背景（Background）

Everyric2 Chrome 擴充套件會在同步歌詞下方顯示 `translation`。目前畫面只確認欄位是否有值，
沒有判斷翻譯是否與原文屬於同一語言。因此中文歌曲若收到中文翻譯，主歌詞、純文字歌詞與
採點／PiP 會顯示兩行近乎相同的內容。

現有的轉譯請求保護也無法完整處理中文：內容層使用的語系偵測會把所有漢字歸為日文，
使中文原文搭配中文目標語言時仍可能發出翻譯請求。即使不再請求，快取或後端既有資料中的
同語言翻譯仍會被直接渲染。

### 問題（Problem）

- 中文原文下方重複顯示中文翻譯，降低歌詞可讀性。
- 各顯示介面各自直接判斷 `line.translation`，沒有一致的顯示規則。
- 只依翻譯設定判斷會受舊快取或資料來源標記錯誤影響。
- 逐行判斷語言則可能把只有漢字的日文歌詞誤認成中文。

### 目標（Goal）

- 原文與翻譯屬於同一語言時，不顯示翻譯列。
- 規則一致套用至主同步歌詞、純文字歌詞、採點與 PiP。
- 日文翻中文、韓文翻中文等跨語言翻譯保持可見。
- 中文原文能被正確判斷為中文，不再因漢字而一律視為日文。
- 不刪除或覆寫翻譯資料，切換目標語言後仍可使用既有資料。

### 非目標（Non-goals）

- 不修改翻譯模型、提示詞或翻譯文字品質。
- 不清除資料庫或瀏覽器中的既有翻譯快取。
- 不重做語言切換 UI。
- 不改變對齊引擎為日文歌詞處理漢字的既有策略。

### 約束（Constraints）

- 語言判斷必須以整首文字為主要依據，不能只看單一漢字行。
- 顯示層只能抑制渲染，不得原地刪除 `line.translation`。
- 混合語言歌曲不可因少數外語行而錯誤隱藏有效翻譯。
- 所有顯示介面必須使用相同的純函式規則，避免行為分歧。
- 不覆寫工作區中與本修改無關的既有未提交變更。

## 方案比較

### A. 只比較目前翻譯設定

若原文語言等於 `translationLanguage` 就隱藏。實作最小，但舊快取、外部歌詞或錯誤 metadata
仍可能顯示同語言翻譯，因此不採用。

### B. 每一行分別偵測語言

能處理逐行混合語言，但日文歌詞中只有漢字的行容易被判成中文，造成真正的中文翻譯被隱藏，
因此不採用。

### C. 全曲判斷搭配單行去重（採用）

以整首原文與整首翻譯分別判斷主要語言；兩者相同時整首隱藏翻譯。兩者不同時仍逐行移除
正規化後與原文完全相同的重複內容。此方案同時處理錯誤 metadata、舊快取與局部重複，
並降低日文純漢字行的誤判風險。

## 詳細設計

### 共用語言判斷

- 在 Chrome 擴充套件的共用語言模組新增純函式，輸入整組歌詞文字並輸出
  `zh | ja | ko | en | unknown`。
- 判斷順序為日文假名、韓文、漢字、拉丁字母；日文只要整首出現假名即判為日文，因此其他
  只有漢字的行仍跟隨整首日文語境。
- 空字串或沒有足夠文字證據時回傳 `unknown`，不因不確定而隱藏翻譯。
- 此判斷只服務顯示與翻譯請求保護，不取代對齊引擎既有的語言策略。

### 翻譯可見性

共用規則接收整首 `LyricLine[]`，產生全曲是否顯示翻譯的結果：

1. 收集非空白原文與非空白翻譯。
2. 任一側無內容或語言為 `unknown` 時，不進行全曲同語言隱藏。
3. 原文與翻譯的主要語言相同時，所有翻譯列不渲染。
4. 主要語言不同時，逐行比較去除空白與常見標點後的文字；完全相同的單行不渲染。
5. 其餘跨語言翻譯正常顯示。

不更動原始 `LyricLine`，讓使用者切換翻譯語言或其他介面重用資料時不會遺失內容。

### 套用介面

- 主同步歌詞：初次建立行元素與重新整理翻譯時使用共用規則。
- 純文字歌詞：建立每行原文／翻譯 DOM 時使用共用規則。
- 採點與 PiP：計算是否有翻譯版面及實際繪製翻譯文字時使用同一結果。
- 內容層發出翻譯請求前，以共用的中文／日文區分修正同語言短路；畫面端仍保留獨立保護，
  以處理快取及外部資料。

## 邊界情況

- 日文歌曲即使部分行只有漢字，只要整首含假名，仍判定為日文。
- 中英混合中文歌曲若主要可辨識文字為中文，中文翻譯視為同語言並隱藏。
- 原文與翻譯語言不同但某行只複製原文時，只隱藏該重複行。
- 羅馬拼音屬於 `pronunciation`，不套用翻譯隱藏規則。
- 無法可靠辨識語言時維持顯示，避免誤刪有效資訊。

## 測試與驗收

- 中文原文＋中文翻譯：主歌詞、純文字、採點／PiP 都不產生翻譯列。
- 日文原文＋中文翻譯：所有介面正常顯示翻譯。
- 日文原文包含純漢字行：依全曲假名判為日文，不誤隱藏中文翻譯。
- 韓文原文＋韓文翻譯：隱藏翻譯。
- 不同語言但單行正規化後等於原文：只隱藏該行。
- 未知語言或沒有翻譯：維持既有版面且不拋錯。
- 中文歌曲搭配中文目標語言：不發出不必要的翻譯請求。
- TypeScript 型別檢查、Chrome 測試與正式建置通過。
