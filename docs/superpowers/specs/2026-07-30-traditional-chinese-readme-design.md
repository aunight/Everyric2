# 繁體中文 README 重整設計

## 背景

目前 README 混合繁體中文、韓文、日文與英文，並保留大量原專案的開發者文件。一般使用者
需要在重複內容與伺服器技術細節之間尋找功能、安裝與使用方式。

## 問題

- 相同資訊以多種語言重複出現，篇幅過長。
- 主要功能與 Chrome 安裝步驟不容易找到。
- 自架伺服器、API、環境變數與 CLI 等內容超出一般使用者需要。
- Fork 新增功能與既有功能必須清楚區分。

## 目標

將根目錄 README 改為面向一般使用者的繁體中文主文件，讓讀者能快速了解功能、完成
Chrome 擴充功能安裝並開始使用，同時保留必要的原作者與授權資訊。

## 非目標

- 不保留自架伺服器、API、環境變數、CLI 與開發指令。
- 不提供韓文、日文或英文的重複使用指南。
- 不修改程式功能、擴充功能介面或建置流程。
- 不把既有的即時音高偵測、顯示模式切換或分數保存列為此 fork 新增功能。

## 限制

- 保留原作者 onpe、原始專案連結、Apache License 2.0、NOTICE 與第三方資料來源。
- 保留 Releases、隱私權政策及現有畫面圖片連結。
- 安裝說明以已發布的 Chrome 擴充功能壓縮檔為主，不要求使用者自行建置。
- 全文使用台灣繁體中文與全形中文標點，指令、網址及產品名稱維持原文。

## 文件結構

1. 專案名稱、簡介與原作者標註
2. 畫面預覽
3. 主要功能
4. 此 fork 新增與調整
5. Chrome 擴充功能安裝
6. 基本使用方法
7. 注意事項
8. 原作者、資料來源與授權

## 驗收方式

- README 不再含韓文、日文或英文說明段落。
- README 不再含自架伺服器、API、環境變數、CLI 或開發章節。
- Releases 下載、`chrome://extensions` 安裝及第一次使用步驟完整。
- Fork 新增功能的描述符合已確認內容。
- Markdown 連結及圖片路徑有效，現有 README 回歸測試同步更新。
