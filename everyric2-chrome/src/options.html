Everyric 권한 설정

자체 호스팅(로컬) 싱크 서버에 접근할 권한을 여기서 허용하거나 철회합니다.

Everyric은 기본적으로 https://everyric.moref.co 싱크 서버를 씁니다. 그 서버 접근은 설치할 때 이미 허용돼 있어 여기서 할 일이 없습니다.

이 페이지는 서버를 직접 돌려서 쓰는 경우에만 필요합니다. 그런 로컬 서버 주소는 자체 호스팅하는 소수만 쓰므로, 설치할 때 모두에게 권한을 요구하지 않고 필요한 사람이 직접 허용하도록 선택적 권한으로 두었습니다. 허용하면 확장이 그 주소로 가사·싱크 요청을 보낼 수 있게 되고, 철회하면 즉시 보낼 수 없게 됩니다.

서버 주소는 유튜브 가사 패널의 설정(⚙)에서 바꿉니다 — 이 페이지에서는 권한만 다룹니다.

로컬 서버 접근 권한

알아 두면 좋은 것

  • 허용은 한 번만 하면 유지됩니다. 확장을 지우면 함께 사라집니다.
  • 확장 업데이트로 이 권한이 회수돼 자체 호스팅 서버가 갑자기 연결되지 않을 수 있습니다. 그때는 여기서 다시 허용하면 됩니다.
  • chrome://extensions의 Everyric 세부정보에서도 사이트 접근 권한을 확인·변경할 수 있습니다. 거기서 바꾼 내용도 이 페이지에 그대로 나타납니다.
  • 포트가 다른 로컬 서버나 제3의 서버 주소는 확장을 다시 빌드해야 쓸 수 있습니다.
